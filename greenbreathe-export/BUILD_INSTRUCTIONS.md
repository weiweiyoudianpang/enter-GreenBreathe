# 青植呼吸 Chrome扩展 - 构建指南

## 📦 构建扩展

### 1. 安装依赖
```bash
pnpm install
```

### 2. 构建扩展包
```bash
pnpm build:extension
```

构建完成后，扩展文件将输出到 `dist/` 目录。

## 🚀 加载到Chrome浏览器

### 步骤：

1. **打开Chrome扩展管理页面**
   - 在Chrome浏览器中访问：`chrome://extensions/`
   - 或点击：菜单 → 更多工具 → 扩展程序

2. **启用开发者模式**
   - 在右上角找到"开发者模式"开关
   - 打开开关

3. **加载扩展**
   - 点击"加载已解压的扩展程序"按钮
   - 选择项目的 `dist` 文件夹
   - 点击"选择文件夹"

4. **验证安装**
   - 扩展列表中应该显示"青植呼吸 GreenBreathe"
   - 浏览器右上角应该出现🌿图标

## ⚙️ 首次配置

1. **点击扩展图标**
   - 打开Popup页面
   - 点击"打开设置"按钮

2. **设置个人信息**
   - 输入昵称（如：小飘）
   - 选择MBTI类型（如：INFP）
   - 调整提醒间隔（默认60分钟）
   - 选择弹窗位置（默认右上角）

3. **保存设置**
   - 点击"保存设置"按钮
   - 等待"✓ 已保存"提示

4. **测试提醒**
   - 点击"测试提醒"按钮
   - 切换到任意网页标签
   - 几秒后应该在页面上看到水墨风弹窗

## 🎯 使用说明

### 正常使用
- 扩展会根据设置的间隔自动弹出提醒
- 弹窗会智能避让全屏、视频、输入等状态
- 提醒内容根据你的MBTI性格定制

### 查看统计
- 点击浏览器工具栏的🌿图标
- 查看今日/本周/累计完成数
- 查看植物成长进度

### 修改设置
- 点击Popup中的"打开设置"
- 或右键扩展图标 → 选项

## 🐛 调试技巧

### 查看后台日志
1. 访问 `chrome://extensions/`
2. 找到"青植呼吸"扩展
3. 点击"service worker"链接
4. 打开开发者工具查看后台日志

### 查看内容脚本日志
1. 打开任意网页
2. 按 F12 打开开发者工具
3. 在Console中查看"GreenBreathe"相关日志

### 重新加载扩展
- 修改代码后需要重新构建：`pnpm build:extension`
- 在 `chrome://extensions/` 点击刷新按钮
- 或使用快捷键：Ctrl+R（在扩展卡片上）

## 📝 常见问题

### Q: 弹窗没有出现？
A: 
1. 检查是否在免打扰时间段
2. 检查是否处于全屏/视频播放状态
3. 检查是否开启了"极简模式"
4. 查看后台日志确认定时器是否触发

### Q: MBTI鼓励语不生效？
A: 
- 确认已在设置页面选择并保存MBTI类型
- 刷新网页重新触发提醒

### Q: 样式显示异常？
A: 
- 内容脚本使用Shadow DOM隔离，理论上不会受网页CSS影响
- 如有问题，请在GitHub提Issue

## 🔄 更新扩展

1. 拉取最新代码
2. 重新构建：`pnpm build:extension`
3. 在 `chrome://extensions/` 点击刷新按钮
4. 检查版本号是否更新

## 📚 项目结构

```
dist/
├── manifest.json          # 扩展清单
├── background.js          # 后台服务工作进程
├── content.js             # 内容脚本
├── options.html           # 设置页面
├── popup.html             # 弹出窗口
├── icons/                 # 扩展图标
│   ├── icon-16.png
│   ├── icon-48.png
│   └── icon-128.png
├── images/                # 资源图片
│   └── ink-wash.png
└── assets/                # 编译后的CSS/JS资源
```

## 🎨 自定义

### 替换水墨背景
1. 准备300×200px的PNG图片
2. 替换 `public/images/ink-wash.png`
3. 重新构建扩展

### 修改主题色
1. 编辑 `src/index.css` 中的CSS变量
2. 主色：`--primary: 120 40% 55%`
3. 重新构建扩展

### 添加更多MBTI类型
1. 编辑 `src/data/mbtiMessages.ts`
2. 为对应类型添加鼓励语数组
3. 重新构建扩展
